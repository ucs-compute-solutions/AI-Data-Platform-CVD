# Demonstration packages

Demonstration packages extend the validated CVD workload companions without
changing their published operating model.

| Package | Status | Start here |
|---|---|---|
| Warehouse Operations | Implementation starter; not yet deployable | [`warehouse-operations/README.md`](warehouse-operations/README.md) |

Each package keeps site-completed inputs, credentials, source media, model
artifacts, rendered manifests, and runtime evidence outside Git. Follow the
package README and pass its offline checks before connecting it to an
OpenShift environment.
