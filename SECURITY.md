# Security

## Reporting a security issue

Do not include credentials, tokens, private certificates, customer data, or
other sensitive information in a public issue.

For a suspected vulnerability in a Cisco product, follow the
[Cisco Security Vulnerability Policy](https://sec.cloudapps.cisco.com/security/center/resources/security_vulnerability_policy.html).
For a repository-specific issue, contact the repository maintainers through a
private organization channel or use a private GitHub security advisory when
that feature is enabled.

## Repository content

The examples in this repository refer to Kubernetes Secret names but do not
contain Secret values. Keep completed input files, rendered manifests,
kubeconfigs, credentials, private certificates, logs, and validation evidence
outside Git.
